# Week 3 Reusable Components and Persistent Navigation

This Next.js project recreates the Pixel Peak design from the Week 3 Figma assignment.

## Pages

Home  
About  
Contact

## Reusable Components

Header  
Sidebar  
Footer  
Button

## Layout Structure

The Header, Sidebar, and Footer are placed in `app/layout.js` so they remain visible on every page. Only the content inside `{children}` changes during navigation.

## Technologies

Next.js  
React  
Tailwind CSS  
App Router

## Run Locally

Install the dependencies:

npm install

Start the development server:

npm run dev

Open http://localhost:3000 in a browser.
